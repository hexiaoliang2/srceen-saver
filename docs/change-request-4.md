**自动判定算法（唯一来源=整体背景明度，写入文档）**：
1. 纯色背景 → 直接用色值的 WCAG 相对亮度（`ImageLoader.ets:132 screenSaverRelativeLuminance`，sRGB 线性化 + 0.2126/0.7152/0.0722 加权）；
2. 图片/离屏模糊图背景 → 背景图**主色**亮度（`effectKit ColorPicker` 对整张解码图取主色 ≈ 主要区域平均色），
   **取样时机**：背景图解码/模糊完成的这一刻算一次；**缓存**：随位图缓存（`CanvasBackground.ets:74 cachedLuminance / :121 计算 / :150-156 luminanceOf`），卡片每次重绘只读缓存，不重复取样；图片未就绪时退回纯色背景判定；
3. 阈值 `0.179`（**实现侧方案，待确认**）：这是"白字对比度=黑字对比度"的数学交叉点（(L+0.05)²=0.05×1.05 ⇒ L≈0.1791），取该点保证纯色背景下所选文字色对比度 ≥4.58:1（覆盖 AA 4.5:1）；L<0.179 → 浅色文字，L≥0.179 → 深色文字。
   （注：你举例的"0.5"阈值会在 L∈[0.18,0.5) 的中间明度背景下选出对比度仅 3.0~4.5 的白色文字，故改用交叉点。）

**3.3 可读性兜底（描边/轻投影）**

- 触发条件（`CardTheme.ets:205-219`）：全局开关「文字投影兜底」打开 **且**（背景为图片/模糊图 **或** 主文字对背景理论对比度 <4.5:1）。
- 参数：`ShadowOptions{ radius: 6px（图片/低对比）或 4px（相册信息条恒启用）、offsetY 1、色=浅墨配 #CC000000 / 深墨配 #CCFFFFFF }`；关闭时 `radius=0`（=无阴影）。
- 开关位置：设置页「文字与图标颜色」区内的「文字投影兜底」（默认开）。
- **不在屏保态添加任何底色/描边形状**，不改变卡片全透明的性质。

**3.4 天气与入口卡片的图标/装饰素材**

- 形式：**程序化矢量绘制**（ArkUI 基础图形 `Circle/Row/Path` + 文本首字），天然"可运行时着色"（颜色全部来自 CardTheme 调色板）；理由：无位图资源、无解码/内存成本、随墨色档实时切换、**100% 自绘、来源合规**，且不引入动画（静止态静态）。
- 深浅两套（`CardTheme.ets:104-148`）：浅墨档配深色背景（对纯黑 ≥3:1 设计），深墨档配浅色背景（对纯白 ≥3:1 设计）；入口图标底色 6 档 + 首字色同步切换（白首字↔深首字），避免"黑字配浅图标"。
- 尺寸档：沿用现有规则 minimal 26/30vp、compact 30vp、full 40/56vp（大卡装饰 0.75 透明度，静态）；1×1 档仅图标+温度（不省略图标、不加装饰），无错位/溢出（截图 s01/s05/s08 的 1×1 天气与 1×1 入口均正常）。
- 应用跳转卡的目标 App 名称/图标沿用既有结论（官方接口不可用 → 自绘中性方案），本次未改其获取方式。
