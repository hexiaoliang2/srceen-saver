## 1. 官方能力核查（HarmonyOS 侧）

### 1.1 应用内嵌其他应用的服务卡片 —— 不可行

| 维度 | 结论 |
|---|---|
| 能力来源 | Form Kit（卡片开发框架）。官方文档口径：Form Kit 是「在**桌面、锁屏等系统入口**嵌入显示应用信息」的框架 |
| 文档依据 | `FAQ/程序框架/卡片开发_Form/如何根据不同尺寸的卡片适配不同的UI/faqs-form-19`、`…/如何将卡片添加至桌面/faqs-form-23`、`开发指南/Ability_Kit_程序框架服务/应用间跳转/拉起系统应用/system-app-startup`（其中提到系统应用可用系统 Picker 等能力） |
| 结论 | 第三方应用**在自身界面内嵌入他人服务卡片**属于桌面/锁屏级能力（宿主侧需系统级授权），**应用内一般不可嵌入**；FormComponent/formHost 方向需核实 `ohos.permission.REQUIRE_FORM` 等受控权限，第三方应用预计不可得 |
| 待核实 | 「本机版本 FormComponent 对第三方应用的可用性」→ 查询路径：API 参考 → Form Kit → ArkTS API（FormComponent / formHost）→ 权限说明 |
| 对功耗/隐私影响 | 不可行，无影响 |

### 1.2 天气：官方数据服务存在但**不对外开放**

| 维度 | 结论 |
|---|---|
| 能力来源 | **Weather Service Kit**（`weatherService`，SystemCapability.Weather.Core），提供实况/逐小时/10 日预报、分钟级降水、预警、指数、天文、潮汐 |
| 文档依据 | `开发指南/Weather_Service_Kit_天气服务/Weather_Service_Kit简介/weather-service-introduction`（核对日期 2026-10-13） |
| **关键限制** | 原文：「**使用限制：Weather Service Kit 当前仅面向系统应用开放，暂不对外开放**」；「本 Kit 暂不支持模拟器」 |
| 结论 | 第三方应用**不可用**；若后续开放，需要 AGC 开通天气服务并申请权限（`FAQ/天气数据服务_Weather_Service_Kit/查询天气数据失败怎么解决/faqs-weatherservice-1` 提到需检查是否已在 AGC 平台开通天气服务和相关权限） |
| 决策点 | 是否在 AGC 侧咨询/申请该服务（若未来开放，可替换为本项目当前的数据源实现） |

### 1.3 应用间跳转（入口卡片的能力来源）

| 维度 | 结论 |
|---|---|
| 能力来源 | 官方 `UIAbilityContext.openLink` + `@ohos.app.ability.OpenLinkOptions`（API 12+，`appLinkingOnly` 控制是否只走 App Linking）；`canOpenLink` 用于「目标应用是否可访问」的预判 |
| 文档依据 | `API参考/Ability_Kit_程序框架服务/ArkTS_API/Stage模型能力的接口/ohos_app_ability_OpenLinkOptions_openLink的可选参数_/js-apis-app-ability-openlinkoptions`、`开发指南/Ability_Kit_程序框架服务/应用间跳转/拉起指定应用/可选_使用canOpenLink判断应用是否可访问/canopenlink`、`FAQ/程序框架/程序框架_Ability/如何判断应用程序是否安装/faqs-ability-142`、`FAQ/程序框架/程序框架_Ability/应用内点击拉起第三方应用失败/faqs-ability-160` |
| 关键限制 | ① `canOpenLink` **不支持**判断 App Linking 形式的目标；② 使用 `canOpenLink` 需要在 `module.json5` 的 `querySchemes` 里声明目标 scheme（API 21 起最多 200 个）；③ scheme 未声明时 `openLink` 会报 `17700056`（见 `FAQ/技术质量/稳定性/点击跳转三方支付时应用闪退/faq-stability-42`） |
| 本项目的取舍 | 入口卡的链接**由用户填写**（不预置任何第三方 scheme/链接），因此不调用 `canOpenLink` 预判，直接 `openLink(link, { appLinkingOnly: false })`，失败统一降级提示「目标应用未安装或链接不可用」 |
| 实测 | 模拟器上 `openLink('https://www.bing.com')` 成功拉起系统浏览器（日志 `entry link opened: …` + 截图 `dA-13`） |

## 4. 待你决策项

1. **Open-Meteo 免费层限非商业用途**：本应用是否商用？若商用需订阅其付费档或更换数据源（可在设置面板里替换实现，卡片 UI 不变）。

5. **入口卡片播放态是否允许点击跳转**？（当前：播放态**不响应**点击，只有编辑态的「打开」按钮可跳转，保持屏保纯净）
6. **悬浮时钟是否要「点击穿透」开关**？（当前：播放态完全穿透，编辑态可交互）
7. **Pixso 第 11 页导出/guid**：缺陷 2 与需求 B 的视觉数值目前均为「自定，待核实」。

## 5. 合规与风险备注（不做结论性判断，仅记录事实与待办）

- Open-Meteo 的使用条款要求署名（本项目已在卡片完整档与设置面板中显示「数据 Open-Meteo」）；其免费档的商业使用限制需由你确认。
- 天气数据源为境外服务，**国内网络可达性未做多点实测**（模拟器上可正常返回数据）。
- 天气卡片只发送「城市名/经纬度」用于查询，不上报任何用户标识；城市名由用户手输，未申请定位权限，未新增任何权限。
- 入口卡片不展示、不缓存第三方内容，不内置第三方名称/图标/链接；跳转目标由用户填写，商标与链接使用由用户自行决定。
